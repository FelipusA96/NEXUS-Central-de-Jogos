# Atualização CrossMath R2 — Valores ampliados

1. Extraia este ZIP na raiz do repositório `NEXUS-Central-de-Jogos`, preservando as pastas.
2. Substitua os arquivos em `jogos/crossmath/`.
3. Inclua os documentos `CHANGELOG.md`, `README.md` e `docs/maintenance/CROSSMATH-VALORES-AMPLIADOS-R2.md` se desejar manter a documentação alinhada.
4. Faça commit e push para a branch publicada pelo GitHub Pages.
5. Após a publicação, abra o CrossMath e pressione `Ctrl + F5`.

## Faixas aplicadas

- Fácil: 1–9.
- Médio: 1–99.
- Difícil: valores-base de 10–999.
- Extremo: valores-base de 100–999.

A atualização também permite entrada de até três dígitos e adapta o tamanho da fonte. Não substitui os arquivos dos outros jogos.
