    MANUAL // PROTOCOLO 002

    Como jogar

    Revele todas as casas sem minas. Números indicam quantas minas estão em volta de cada casa (incluindo diagonais).

    • Mouse: clique esquerdo para revelar e direito para marcar/desmarcar bandeiras.
    • Celular: escolha os botões Revelar ou Bandeira acima do tabuleiro.
    • Teclado: use as setas para navegar, Enter para realizar a ação selecionada e F para marcar bandeira.
    • Abertura rápida: clique em um número já revelado para abrir vizinhas quando houver a quantidade correta de bandeiras ao redor.
    • Vitória: abra todas as casas seguras. Bandeiras não precisam estar todas colocadas.
