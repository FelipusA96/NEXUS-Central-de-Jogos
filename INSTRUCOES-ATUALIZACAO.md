# Atualização NEXUS — banco de palavras

1. Extraia este ZIP na raiz do repositório `NEXUS-Central-de-Jogos`.
2. Mantenha a estrutura de pastas e permita substituir os arquivos existentes.
3. Faça commit e push para publicar no GitHub Pages.
4. Abra os jogos e atualize com `Ctrl + F5`.

O pacote incremental inclui somente o banco compartilhado, os arquivos alterados dos dois jogos e este relatório. Para substituir a instalação inteira, use o pacote completo.
